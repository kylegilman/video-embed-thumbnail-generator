# Videopack 5.0 Official Documentation

Welcome to the official documentation hub for **Videopack 5.0**.

Videopack is a complete video publishing, encoding, and gallery management solution for WordPress. Whether you are using the modern Gutenberg Block Editor or the Classic Editor, Videopack makes self-hosting video seamless, responsive, and performant.

---

## 🌟 What's New in Videopack 5.0

[videopack id="sample_intro_video" title="Videopack 5.0 Overview Video" autoplay="false"]

Videopack 5.0 brings major enhancements to your video workflow:

1. **Native Gutenberg Blocks**: Purpose-built blocks for single video players, responsive video grid galleries, and playlists.
2. **Classic Editor Shortcode GUI**: Visual player placeholders and interactive modal dialogs for inserting shortcodes effortlessly.
3. **FFmpeg-Free Canvas Watermarks**: Overlay custom graphic watermarks onto video thumbnails directly inside your web browser.
4. **REST-Driven Administration**: Completely redesigned, responsive React settings and queue management dashboard.
5. **Unified Shortcodes & Action Hooks**: Clean standardized parameter names under `videopack_`.
