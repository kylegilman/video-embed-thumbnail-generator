# Videopack 5.0 Documentation

Welcome to the official documentation for **Videopack 5.0** (formerly Video Embed & Thumbnail Generator).

Videopack is a powerful WordPress plugin that provides responsive video players, custom thumbnail generation, resolution switching, video galleries, and cloud/server encoding.

---

## What's New in Videopack 5.0

Videopack 5.0 represents a complete architectural evolution of the plugin:

- **Native Block Editor Support**: Introducing dedicated Gutenberg blocks for single videos, video galleries, and video lists.
- **Classic Editor Shortcode GUI**: Visual placeholder blocks and interactive shortcode builder when using the Classic Editor.
- **FFmpeg-Free Watermarking**: Add watermark overlays to video thumbnails directly in your web browser without requiring FFmpeg on your web host.
- **Redesigned Admin & Options**: A modern React-based administration dashboard powered by a unified REST API options engine.
- **Unified Shortcodes & Hooks**: Standardized parameter names and filter/action hooks under the clean `videopack_` prefix.
