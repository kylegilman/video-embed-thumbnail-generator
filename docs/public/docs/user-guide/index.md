# Videopack 5.0 User Guide

Welcome to the Videopack User Guide! Videopack gives you total control over self-hosted videos, video galleries, and thumbnails in WordPress.

---

## Core Capabilities

- **Responsive Video Players**: Powered by Video.js with full resolution switching (1080p, 720p, 480p, etc.).
- **Flexible Thumbnail Generation**: Generate thumbnails automatically via server-side FFmpeg or interactively inside your web browser.
- **Watermarks**: Overlay watermark graphics onto generated thumbnails without server dependencies.
- **Gutenberg & Classic Editor Support**: Embed videos using native block editor components or classic shortcodes.
- **Popup Video Galleries**: Showcase collections of media library videos in clean, responsive grid galleries.
