# Gutenberg Block Editor Integration

Videopack 5.0 introduces native WordPress Block Editor (Gutenberg) integration, featuring three distinct blocks:

1. **Videopack Video Block** (`videopack/video`)
2. **Videopack Gallery Block** (`videopack/gallery`)
3. **Videopack List Block** (`videopack/list`)

---

## 1. Videopack Video Block

The **Videopack Video** block allows you to insert individual video players into posts or pages with live editor previews and sidebar controls.

### Adding a Video Block
1. In the Block Editor, click the `+` block inserter button.
2. Search for **Videopack Video** and insert it.
3. Select a video from your Media Library or upload a new video file.

### Block Controls & Settings
- **Player Controls**: Toggle autoplay, loop, muted, controls, and playback speed menu.
- **Poster Image**: Choose custom thumbnails or select from generated frames.
- **Subtitles & Captions**: Attach `.vtt` text tracks directly within the block inspector.
- **Resolution Switching**: Automatically links alternate resolution versions available for the selected video.

---

## 2. Videopack Gallery Block

The **Videopack Gallery** block builds responsive grid galleries of video items with popup lightboxes.

### Adding a Gallery Block
1. Insert the **Videopack Gallery** block into your post.
2. Choose videos from your Media Library or filter by taxonomy tags/categories.

### Key Settings
- **Columns**: Adjust responsive column count (1 to 6 columns).
- **Pagination**: Enable page-based navigation or load-more triggers for large video libraries.
- **Player Skin & Styling**: Customize title overlays, play button colors, and hover effects.

---

## 3. Videopack List Block

The **Videopack List** block displays a clean list or playlist layout of selected videos, ideal for course modules, video series, or podcasts.
