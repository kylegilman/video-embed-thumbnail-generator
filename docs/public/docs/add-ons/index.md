# Videopack Add-ons Overview

Videopack can be extended with official add-on plugins to provide advanced streaming, cloud encoding, monetization, and authentication features.

---

## Available Add-ons

### 1. [Videopack Player Pro](player-pro.md)
Enhances Videopack with enterprise-grade features:
- **Cloud Transcoding**: Delegate video resolution encoding to **AWS Elementals MediaConvert**.
- **Secure Media Authentication**: Restrict access to videos using signed cookie authentication via **Amazon CloudFront** and **Google Cloud CDN**.
- **Pro Player Features**: Additional skins, custom player overlays, analytics, and enhanced playback control options.

### 2. [Videopack Ads](ads.md)
Monetize your video content:
- **Pre-Roll, Mid-Roll, and Post-Roll Ads**: Embed video advertisements into self-hosted content.
- **VAST/VMAP Compliance**: Integration with standard ad network servers and custom video ad tags.
